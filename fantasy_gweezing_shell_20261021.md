## Method / assumptions

- Engine: pvpoke-sim v2 (battle3v3.js), perfect play both sides, no human-error model — same as all prior Fantasy Cup sims in this folder.
- Meta: fantasy_meta_teams.json, 24 hand-built teams, standard PvPoke sets, rank-1 default IVs. The meta includes the rank-1 version of this shell.
- Pooling: 4 independent process runs per variant (3 for as-is), 10 reps × 24 teams per run per order; numbers above were read from the per-run JSON files on disk (fantasy_gweezing_shell_*_run*.json), not from run summaries.
- H2H opponents: rank-1 builds from fantasy_alts_h2h.js (identical specs to the prior alternatives report). H2H is 10 reps per line, single process.
- Build costs computed from the gamemaster tables via fantasy_candidates.js (dust bands + thirdMoveCost: G-Fisk unlock is 75,000 dust + 75 candy, more than the usual 50k species).
- Nothing was changed on the game account. Sim only.

Files: fantasy_gweezing_shell.js, fantasy_gweezing_shell_h2h.js, fantasy_gweezing_shell_*_run*.json, fantasy_gweezing_shell_h2h_results.json — all in ~/workspace/pvpoke-sim/
